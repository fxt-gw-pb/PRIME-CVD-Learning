# 质量控制与交付边界

## 已完成并实际检验（2026-09-27，macOS arm64，Python 3.11）

**官方数据**：`python run.py download` 从 Figshare 下载 Asset1 v2 与 Asset2，两个文件的提供者 MD5 均核验通过；来源记录见 `data/raw/manifest.json`。

**完整流水线**：`python run.py all` 在官方 50,000 人数据上端到端运行：患者级划分（训练 35,000 / 验证 7,500 / 测试 7,500，测试集仍封存）、基础回归、KM、普通与 L2 Cox、训练内三折交叉验证、验证集评价、EMR 重建、单位敏感性实验和 HTML 报告。验证集主要结果：

| 指标 | 普通 Cox | 训练内 CV 选中（alpha = 0.001） |
|---|---|---|
| Harrell C | 0.875 | 0.875 |
| 截断 IPCW C（5 年） | 0.874 | 0.874 |
| 5 年 IPCW AUC | 0.877 | 0.877 |
| 5 年 IPCW Brier | 0.0273 | 0.0273 |
| 相对训练 KM 常数风险的 Brier 改进 | 29.3% | 29.3% |
| 平均预测 5 年风险 / 1 − KM(5) | 4.05% / 4.03% | 4.06% / 4.03% |

训练内 CV 的三个 alpha 平均 Brier 几乎相同（0.02790、0.02790、0.02799），说明在 3.5 万人、14 个参数的情况下惩罚几乎没有作用。这本身就是一个值得解释的结果。

**EMR 重建**：官方三张表的 19 种诊断写法、35 种检验写法、2,500 条 mmol/mol 单位的 HbA1c、1,000 条英尺英寸身高都能被识别。与 Asset1 对照：诊断、HbA1c、eGFR、SBP、IRSD、结局完全一致；年龄误差 ≤ 0.005 岁（两位小数舍入）；BMI 中 10,000 个由身高体重派生的值有舍入误差（最大 0.63 kg/m²）。

**单位错误实验**（其他预测变量固定，只替换 HbA1c）：故意漏掉 mmol/mol → % 的换算后，验证集 Harrell C 从 0.875 降到 0.843，Brier 从 0.027 升到 0.065，平均预测 5 年风险从 4.1% 翻倍到 8.3%。

**自动化测试**：51 项中 50 项通过，1 项跳过（可选的 scikit-survival 交叉核验，未安装）。覆盖数据泄漏护栏、单位错误、重复连接、删失权重、概率边界、模型序列化、测试集锁定，以及官方数据全部术语与单位的识别、BMI 派生和端到端重建核对。

**笔记本**：17 份按周编号的笔记本全部在官方数据上执行通过，结果见 `outputs/notebook_execution.json`。

具体命令与结果以 `TESTING.md` 为准。不能把代码"写了"当作"已跑通"。

## 结果解释限制

基线统计只描述相应的数据集（精讲篇为全部 5 万人，工程篇为训练集）。多变量条件关联不自动等于因果；惩罚系数不附未经校正的推断区间。校准图只有分组结果，不能单凭点落在对角线附近就宣称模型可靠。性能指标目前只报告点估计，没有 bootstrap 不确定性。

预测与删失假设有明确的适用范围。病历版不是独立的外部队列，日期不可逆，缺失和舍入的信息不能恢复。"生存时间不可恢复"指不能从病历版重现 Asset1 中每个人的精确随访时间，并不否认可以另行定义近似的时间分析（第 10 周 a 量化了近似带来的偏差）。

这是一份合成数据：模型结果不能用于临床决策，也不是真实的医学发现。
