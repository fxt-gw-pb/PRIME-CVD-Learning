# 核心方法与实现范围

## 1. 预测问题

主任务是使用基线特征估计从基线起五年的CVD事件风险。观察到的结局为 `(T, δ)`，其中T为事件或删失时间，δ为事件标志。不能把随访两年后删失者当成已知的五年阴性。

数据按患者分为70%训练、15%验证、15%测试；按事件状态分层，固定种子3407。分类练习与生存练习使用同一患者划分。分层用于保证事件数量分布，不把结局作为输入特征。

## 2. 预处理

数值先按事先规定的临床单位缩放，再用训练数据的均值和标准差标准化。年龄10岁、BMI5单位、SBP10mmHg、eGFR10单位、HbA1c1个百分点。二元变量保持0/1，之后与其他变量一起标准化以便L2惩罚。

IRSD以5为参考，吸烟以non为参考。编码器限定允许输入列，拒绝cvd_event、cvd_time和患者标识。训练时恒定的列会移除并记录；新数据若出现该列新取值则报错。中位数仅由当前训练折学习；整个队列先插补或标准化会造成泄漏。[S3]

## 3. Cox与岭惩罚

假设 `h(t|x)=h0(t) exp(xβ)`。模型参数通过statsmodels的Cox部分似然与梯度估计，采用Breslow处理并列事件时刻。[S4]

优化目标为 `−log_partial_likelihood / n + alpha × sum(beta²) / 2`。这是纯L2惩罚；alpha=0为普通Cox。数值alpha的含义依赖损失缩放，不可直接拿去与其他软件的penalizer数值比较。[S5]

基线累计危险由训练集的事件时刻和风险集用Breslow估计，按事件跳跃后的右连续函数求值；五年风险为 `1−exp{−H0(5)exp(xβ)}`。模型保存中对线性预测值做中心化以稳定指数，预测时相应还原。

普通Cox的HR及95%CI来自未惩罚模型的信息矩阵，转换回临床单位。惩罚模型只输出收缩后的系数和HR，不伪造未经调整的推断性CI/p值。多变量HR是条件危险率比，不是五年风险比，也不自动具有因果含义。

训练内分层三折CV比较alpha={0,0.001,0.01}，按平均五年IPCW Brier最小选择。每个训练折独立拟合编码器、Cox和基线危险。验证集不参与自动模型选择；测试集需显式解锁。

## 4. 删失分布与IPCW

记训练集估计的删失生存函数为 `G(t)`，用反向KM估计；事件和删失发生在同一时刻时，反向KM先排除结局事件。事件权重采用 `G(T−)`，控制组采用 `G(t)`。对于连续事件时间，它与常见实现等价；存在大量离散时间并列值时必须明确所用约定。[S6]

五年内观察到事件者权重为 `1/G(T−)`；观察超过五年的无事件者权重为 `1/G(5)`；五年前删失者权重为0，而不是已知阴性。边际IPCW需要删失与结局的独立性及训练/评价删失机制可迁移等假设。真实数据存在协变量依赖的失访时，可能需要条件删失模型或其他方法。

预测时间必须严格小于训练和评价数据的最大观察时间，且G(5)不低于配置阈值0.05。程序遇到支持不足会报错，不用极小常数偷偷掩盖除零风险。

## 5. 评价指标

__Harrell C__：比较较早事件者和可比较者的风险排序。风险分数越高表示危险越高；相同风险计0.5。同刻两事件不比较，同刻事件与删失可比较。

__截断IPCW C__：主要比较较早事件发生在五年以内的配对，以 `1/G(T−)²` 加权，作为Uno型估计。报告明确限定时间窗口。

__五年累计/动态AUC__：病例为五年内观察到事件者，对照为观察超过五年者；按上述IPCW加权。不是把所有cvd_event=0直接送入普通ROC。

__IPCW Brier__：以全评价样本数n为分母，对事件/非事件的平方概率误差按删失权重加权。早期删失者贡献0，而不是从分母中简单删除。同时报告训练KM常数风险基线的Brier及相对改进，避免仅凭低事件率得到很小Brier就自我肯定。[S6]

__校准__：训练集预测风险确定分组边界；在验证/测试每组内计算平均预测风险和 `1−KM(5)`。图中区间为观察风险的点态log-log 95%CI；不是个人预测区间。事件为0或KM在边界时，代码不绘制虚假的零宽区间。低事件数和随访支持不足的组明确标记。分组KM同样依赖组内删失假设，并不能替代更细致的校准方法。

## 6. 比例风险假设

代码输出训练集Schoenfeld残差和年龄残差随log事件时间的探索图。__这不是Grambsch–Therneau正式全局检验，也没有宣布所有变量通过PH检验。__ 正式研究应补充相应诊断、非线性评估，必要时调整模型；不要简单增加“基线变量×每人最终随访时间”作为预测特征，这会引入结局信息。

## 7. 数据工程与敏感性

Asset2仅用于重建。主流程对重复测量、未知疾病和未知单位停止并要求审查。患者跨表必须使用ID连接，`validate="one_to_one"`用于已经聚合的队列表，不用于未经处理的原始一对多记录。

单位错误实验固定Asset1其他预测变量，仅替换从病历表得到的HbA1c，比较正确转换与故意未转换。它是受控错误传播实验，既不是纯EMR模型验证，也不是外部验证。

## 7.1 BMI 与身高体重

官方 Asset2 中 80% 的人直接记录 BMI（单位列为空，按定义视为 kg/m² 并计数记录），20% 只记录身高和体重。重建时优先使用直接记录值；否则用同一病历中的实测值按 `BMI = 体重(kg) / 身高(m)²` 派生，英尺英寸身高先换算为厘米（`5'12"` 这类未进位写法按 5×12+12 英寸处理）。每个值的来源写在 `BMI_source`；只有身高或只有体重时保留缺失。派生值带身高、体重舍入误差（与 Asset1 相比最大约 0.63 kg/m²），不从 Asset1 回填。

## 7.2 两个 Cox 实现

工程篇与流水线使用本包基于 statsmodels 部分似然的实现。精讲篇为了讲解方便使用 lifelines，并设置 `fit_options={"step_size": 0.5}`：糖尿病这类强效应下，lifelines 默认的牛顿法步长会发散，且不报错地返回 HR ≈ 0。设置后结果已与 R `survival::coxph` 核对，一致到小数点后第 3 位。两者在全部数据与 70% 训练集上的 HR 略有差异，来源于样本不同，而不是方法不同。
