# 项目章程：为什么做，做到什么程度

## 学习对象与最终目标

面向有医学背景、Python与数据分析基础较弱的学习者。按12周、每周约6–8小时规划，只选择Python主线。有精讲篇的周先学 a（讲概念），再做 b（规范工程流程），见 `02_learning_plan_12_weeks.md`。最终能够从数据定义开始独立完成一套可解释、可核对、可复现的分析，并清楚说明哪些结论不能从数据推出。

最终题目可写为：“使用PRIME-CVD学习心血管风险预测：从数据理解、生存建模到病历重建”。官方数据由 `python run.py download` 下载并核验；如果只使用了 `data/demo` 演示数据，必须改称“使用独立演示数据验证PRIME-CVD学习工程”，不能报告为官方数据研究。

## 四个层次，不混成同一个研究问题

__描述层__：年龄、BMI、吸烟和共病如何分布？

__关联层__：在预先指定的多变量模型中，某因素与收缩压、基线糖尿病或CVD危险率的条件关联是什么？不直接称为因果效应。

__预测层__：使用基线特征估计从基线起五年的CVD事件风险，并在保留数据上评估区分度、校准和误差。

__数据工程层__：如何从病历式主表、慢病表、检验表恢复可恢复的基线信息？哪些字段因缺失、舍入或转换而不能精确恢复？

## 范围和排除项

主线包括经典回归、生存分析、关系型数据清洗、验证和复现。主线不包括影像、病理、深度学习、真实疾病亚型发现、临床阈值制定、真实患者部署或新危险因素的临床发现。因果图用于理解生成假设，本工程不把调整后的HR解释为干预效果。

## 完成标准

从未改动的源文件出发，依次生成数据审查、固定划分、训练与验证结果、重建审查、冻结模型和最终报告。每个结果注明数据来源。能用自己的语言解释删失、OR、HR、五年绝对风险、训练/验证/测试的区别，以及“同一人两种数据表示不是外部验证”。

个人报告至少包含问题、数据、方法、主要图表、错误核查和局限。成功不是AUC超过某个人为目标，而是方法与解释都经得起复核。
